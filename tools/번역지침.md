# 번역 지침 — 劇団おもかげ「春を待つ」 한국어판

작품: 일본 웹 ARG. 소극단 「극단 오모카게」의 평범한 홈페이지를 둘러보다가 숨은 내부 기록(records/)에 들어가면,
단장 쿠로사키가 죽은 여동생 미나를 단원에게 「재연」시킨 일을 시작으로, 유족의 의뢰를 받아 고인을 단원에게
덮어씌워 「출하」하는 「재연 서비스」를 운영해 왔다는 사실이 드러난다. 지금은 신입 단원 타카기 미사키가
그 대상이다. 끝에 고발하느냐 마느냐로 엔딩이 갈린다. 원작자 허락을 받은 한국어판.

## 작업 방식
- `python tools/tr.py dump <파일 조각...>` 로 미번역 조각을 본다. 형식: `번호<TAB>종류<TAB>원문`, 줄바꿈은 ⏎.
- 결과는 `{ "omokage/파일경로": { "번호": "한국어", ... } }` JSON 으로 `tools/patches/<이름>.json` 에 UTF-8 저장.
  번역문 안 줄바꿈도 ⏎ 로 쓰면 원문 모양으로 복원된다. **catalog.json 은 직접 고치지 않는다.**
- 저장 후 `python tools/tr.py check tools/patches/<이름>.json` 로 깨짐 검사(오류 0 이어야 함).
- 용어·인명·검색어는 `tools/glossary.json` 을 반드시 따른다.

## 형식 규칙
- `<b>`·`<a>`·`<span>` 등 태그, `${…}` 는 그대로. 앞뒤 공백은 tr.py 가 복원하니 신경 쓰지 않아도 된다.
- 속성값(종류 a)에는 큰따옴표 `"` 금지, 본문(t)에는 `<` 금지. 따옴표는 「」『』 사용.
- 원문이 줄을 여러 조각으로 잘라 놓은 곳(시처럼 한 줄씩)은 **조각 수·순서 그대로**, 이어 읽었을 때 자연스러운
  한국어가 되게 조각마다 나눈다(한국어 어순 때문에 조각 경계를 조금 옮기는 건 괜찮다).

## 퍼즐 보존 — 가장 중요
- 내부 기록 검색창은 **본문에서 눈에 띄게 따로 떨어진 낱말**(예: 「俺の 信奉者 みたいだと」, 「妹が 蘇った と」,
  「"半生"」, 「"親友"」, 「同意書」, 「ライフスタイル」, 「家族」, 「アウトドア」, 「"SNSアカウント"」, 「"劇団員ページ"」,
  「劇団員手引き」, 「次期公演」, 「再演サービス」, 「出荷」, 「美奈」)을 그대로 쳐서 다음 페이지를 연다.
  이 낱말은 glossary 「_검색어」의 한국어를 **글자 그대로**, 원문처럼 **따로 떨어진 조각/따옴표 그대로** 둔다.
  예: 「蘇った」 조각은 「되살아났다」 한 조각으로. 활용형을 바꾸지 말 것.
- 이름·날짜·숫자·퍼센트·시간·금액은 그대로.

## 문체
- 공개 홈페이지: 극단의 정중한 안내문 (~합니다/~입니다).
- 내부 문서(지침·매뉴얼·기록): 딱딱한 사무체, 명사형 종결(「~할 것」「~함」「~하지 말 것」「확인됨」).
- 단장 기록(diary)·「소감」·「쿠로사키 메모」: 쿠로사키의 독백 반말(「~했다」「~였다」).
  「妹」→「동생」(쿠로사키의 여동생 미나). 「あいつ」→「그 녀석/걔」 문맥대로.
- TRUE END 뉴스: 한국 인터넷 기사체. 댓글은 짧은 인터넷 댓글 말투.
- **직역 금지 — 한국어로 처음 쓴 것처럼.** 단, 단서·호칭은 지킨다.
