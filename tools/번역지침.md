# 번역 지침 — 『その名前は館に眠る』 한국어판

작품: 일본 웹 추리 ARG. 수학여행 버스가 산사태로 절벽 아래로 떨어지고, 살아남은 중학생들이
산속 저택으로 도움을 청하러 갔다가 차례로 죽는다. 플레이어는 외부 조사원으로서, 초능력 수사관
두 명(사이코메트리·패럴렐 월드)이 물건·방에서 읽어 낸 「음성 기억」(대화록)을 읽고
24명의 이름·사인·사망 요인을 명부에 채운다. 원작자 허락을 받은 팬 번역이다.

## 작업 방식
- `python tools/i18n.py dump <파일 조각...>` 로 미번역 문자열을 본다. `[번호] (종류) '원문'`.
- 결과는 `{ "nameisasleep/파일경로": { "번호": "한국어", ... } }` 형태 JSON 으로
  `tools/patches/<이름>.json` 에 UTF-8 로 저장한다. **catalog.json 은 직접 고치지 않는다.**
  (메인이 `python tools/i18n.py set` 으로 반영한다.)
- 저장 후 `python -c "import json;json.load(open('tools/patches/<이름>.json',encoding='utf-8'))"` 로 JSON 이 깨지지 않았는지 확인.
- 용어·인명은 `tools/glossary.json` 을 반드시 따른다.

## 형식 규칙 (어기면 사이트가 깨진다)
- dump 에 보이는 것은 파이썬 repr 이다. 원문에 `\\n` 으로 보이는 것은 JS 소스 안의 글자 그대로의
  `\n`(역슬래시+n) 이다 → 번역문에도 역슬래시+n 두 글자로 넣는다. JSON 에서는 `"\\n"` 으로 써야 한다.
  원문에 `\n` 으로 보이는 것(HTML 텍스트의 실제 줄바꿈)은 실제 줄바꿈 → JSON 에서 `"\n"`.
  **줄바꿈 위치·개수는 원문과 같게** (한 줄 길이도 원문과 비슷하게).
- (js) 종류는 큰따옴표 `"…"` 안의 JS 문자열이다. 번역문에 **큰따옴표 `"` 를 넣지 말 것**(「」『』 사용).
  작은따옴표 `'` 도 피한다.
- `<b>…</b>`, `<br>`, `<a …>`, `<details><summary></summary>…</details>`, `${…}` 는 그대로 유지.
  `<b>` 로 감싼 낱말은 검색 단서이니 한국어에서도 같은 낱말을 `<b>` 로 감싼다.
- 앞뒤 공백·줄바꿈(텍스트 조각 앞뒤의 `\n  ` 등)은 원문 그대로 둔다.
- `***` 로 시작하는 것은 효과음·상황 묘사(지문). `***` 는 유지하고 「~하는 소리.」 식 간결한 문어체.
- 원문이 짧은 조각(「」や「 같은 것)이면 앞뒤 조각과 이어 읽히게 조각 단위로 맞춘다.

## 문체
- 학생들끼리는 반말, 선생님(마코토)에게는 존댓말. 학생이 선생님을 「マコトちゃん」이라 부르는 건
  「마코토 쌤」 정도의 친근함 — 「마코토 쌤」으로 통일.
- 「〜くん」→ 이름만 또는 「〜」(반말 호칭), 성으로 부르는 「サトウさん」→「사토 씨」,
  「ハセガワ先生」→「하세가와 선생님」. 성으로 부르는지 이름으로 부르는지는 **원문 그대로 유지**
  (누가 어느 성·이름인지가 퍼즐이다). 성·이름을 바꾸거나 합치지 말 것.
- 사이코메트리(「〜っす」 말투, 「あたし」) → 「~슴다/~임다」 같은 군기 든 후배 말투(예: 설명하겠슴다, 그렇슴다).
  패럴렐 월드 → 상냥한 반말(「~야」「~해 줘」).
- 정체불명 소녀의 목소리(보라색 배경 대사) → 어린아이가 속삭이는 듯한 반말.
- 일본 배경은 그대로 둔다(엔, 지명, 학교 제도 등).

## 퍼즐 보존
- 이름·사인·사망 요인을 추리하는 단서(누가 누구를 어떻게 불렀는지, 소리, 시계 종소리 횟수 등)는
  빠짐없이·정확히 옮긴다. 의역하다가 단서를 흐리거나 덧붙이지 말 것.
- 말장난·글자 읽기 등 한국어로 옮기면 깨지는 단서가 있으면 번역은 하되,
  `tools/patches/<이름>_notes.md` 에 원문·번역·문제점을 적어 둔다.
- 검색어(방·물건 이름)는 glossary 의 「_검색어」 낱말을 그대로 쓴다.
