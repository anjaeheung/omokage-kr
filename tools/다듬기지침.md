# 직역투 다듬기 지침

콘테 요청: 「일본어가 직독직해된 거 없어?」 — 번역문이 일본어 구조를 그대로 옮긴 티가 나는 곳을 찾아 자연스러운 한국어로 고친다.

## 방법
- `tools/catalog.json` 의 맡은 파일 항목을 ja/ko 나란히 읽는다(파이썬으로 뽑아 볼 것. catalog.json 은 직접 고치지 말 것).
- 고칠 항목만 `{ "nameisasleep/파일": { "번호": "새 한국어" } }` 로 `tools/patches/polish_<이름>.json` 에 저장.
- 고친 내역은 `tools/patches/polish_<이름>.md` 에 「번호 | 전 | 후 | 이유」 표로.
- 형식 규칙은 `tools/번역지침.md` 그대로(역슬래시+n·실제 줄바꿈·<b>·<small>·${} 개수 유지, (js) 는 큰따옴표·작은따옴표 금지). 저장 뒤 개수 검사 스크립트로 확인.

## 찾을 것 (예)
- 일본어 어순·조사 그대로: 「~의 ~의」 남발, 「~에 있어서」, 「~하는 것이 가능」, 「~라고 하는」, 「~적인」 남용, 불필요한 「그」「이」.
- 일본어식 표현 직역: 「잘 부탁해」 남발, 「수고했어」 오용, 「~해 버렸다」 남용, 「역시」「과연」 기계적 번역, 「~인 거야」 남발, 「어째서」 대신 「왜」 가 자연스러운 곳.
- 감탄사·말끝: 「에?」「하아?」「그치?」 등이 한국 10대 말투로 어색하면 고친다. 중학생 반말은 실제 한국 중학생이 할 법하게.
- 지문(***)은 간결한 한국어 문어체. 「~하는 소리.」 반복이 지나치면 자연스럽게 변주 가능(뜻 유지).
- 존댓말·반말이 원문 관계와 맞는지.

## 건드리지 말 것
- 단서: 누가 누구를 성/이름/별명으로 부르는지, 소리·횟수·시간·사물 이름, <b> 낱말, 검색어(glossary 「_검색어」 낱말 — 제목과 본문에서 그 낱말 그대로).
- 인명 표기, 「마코토 쌤」, 사이코메트리 「~슴다」 말투, 역주 <small>.
- 이미 자연스러운 문장은 고치지 않는다(바꾸기 위한 바꾸기 금지).
